# Atmovio 6.0.1 upgrade notes

The new workspace groups everyday work into Cameras, Moments, My Videos and Studio. Advanced AI evidence, filters and processing details are collapsed. The interface remains Czech.

- Camera playback uses HLS for live view and recorded video. Mark OD–DO on the device-local timeline to save up to six hours. Gaps remain visible; saving available footage across an outage requires an explicit checkbox. Playback maps elapsed media time back to the recording clock.
- Overlapping automatic clips from one camera are joined into a bounded range. Old clips stay available until the replacement is ready; missing source recordings prevent consolidation. Sources referenced by saved Studio projects are retained by automatic cleanup.
- Studio saves editable projects, including trim, speed, music offset/volume/fades, a versioned intro, text and subscribe/share callouts. Re-editing a rendered video creates another version. Publishing is a separate action.
- The updater validates a copy of the configuration with Frigate 0.18.2 before stopping the old recorder. It backs up the stopped database and configuration, then checks the new API and previously active cameras. Failure restores the old image, configuration and database. Media is not moved. The restart causes a short recording gap.
- Backups live under `/opt/nvr/atmovio/backups/`. Diagnostics group repeated errors, support resolved status and export redacted JSON. Review free text before sharing a diagnostic export.

See the [Czech walkthrough](cs/verze-6.0.md) for the full user flow, and [installation](install.md) for requirements.

Update older installations through **Nastavení → Systém → Aktualizace → Zkontrolovat teď → Nainstalovat verzi 6.0.1**. The updater downloads the release asset and verifies its checksum. Studio switches to a full-width music or intro workspace when that tool is selected; the source video stays in the trimming tool.
