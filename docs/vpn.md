# Remote cameras over WireGuard

*[Česky](cs/vpn.md)*

A camera in another place (cottage, parents' house, workshop) can be recorded by the Pi at home if the Pi can reach
its network. Two options:

1. **Your router does it** (site-to-site VPN between the two routers, or the remote router is reachable). Then just add
   the camera with its remote address – nothing to configure in SkyWatch.
2. **The Pi itself is a WireGuard client** of the remote router. This is what **Nastavení → Síť a VPN** is for.

## Setting up option 2

1. On the *remote* router (Mikrotik, OpenWrt, Fritz!Box, UniFi, Teltonika, …) create a **WireGuard peer/client** for the Pi
   and download the generated client config (`[Interface] … [Peer] …`). Do not edit it.
2. In SkyWatch → Síť a VPN → *Pro pokročilé: WireGuard tunel* paste the **whole config** and click **Uložit a aktivovat**.
3. Enter the remote camera's IP in *Ověřit* (ping) – it should answer. Then add the camera via **Vyhledat kamery** with the
   remote subnet (e.g. `10.10.10.0/24`) or manually with `rtsp://10.10.10.4:554/…`.

SkyWatch is a **split tunnel by design**: only traffic to the remote camera(s) goes through the tunnel; e-mail, AI, the webhook
and your home LAN stay on the normal connection. It therefore rewrites the pasted config:

- drops `DNS`, `PreUp/PostUp/PreDown/PostDown`, `Table`, `SaveConfig`, `FwMark` (and tells you);
- replaces `AllowedIPs = 0.0.0.0/0, ::/0` with the concrete remote networks (derived from the tunnel `Address` and the IPs
  of your remote cameras, narrowed to `/32` hosts where possible);
- refuses a config whose `AllowedIPs` would swallow your home network or the default route;
- after start it verifies that the gateway and the internet do not go through the tunnel – otherwise it stops the tunnel and
  restores the previous config; a watchdog checks the same every minute and after reboot.

The private key is stored only in `/etc/wireguard/wg-remote.conf` (root, 600). When you edit the config later, the key is
kept unless you paste a new one; the UI never shows it.

## Export / import

- **Export:** the effective config (without the private key) is shown on the page for copying; the full file is `/etc/wireguard/wg-remote.conf` on the Pi.
- **Import:** paste any client config generated by your router or `wg genkey` tooling – the format is the standard `wg-quick` one.

## Troubleshooting

- *Ping fails but RTSP works* – some cameras block ICMP; try adding the camera anyway.
- *Tunnel stops itself* – the config contained the home network or a default route in `AllowedIPs`; see **Logy → VPN**.
- *Handshake never completes* – wrong endpoint/port or the remote router's firewall; `wg show` output is on the Logy → VPN page.
- Bandwidth: stream the remote camera at 1–2 Mbit/s (sub stream as main if necessary); uplinks at cottages are small.
